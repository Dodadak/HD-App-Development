# Pleos 운전 점수 업적 배지

## 파일 구성
- earned/: 받음 SVG 16개
- locked/: 잠김 SVG 16개. 진행 중 상태의 기본 도형으로도 사용
- upgrade/frames/: 30fps, 0~1.5초의 SVG 46개(마지막 프레임은 도착 상태)
- upgrade/clean_streak_2_to_3_animated.svg: 브라우저용 독립 실행 애니메이션 SVG. 1회 재생 후 끝 상태 유지. 다시 열면 재생
- upgrade/keyframe_{start,middle,end}.svg: 시작·중간·끝
- manifest.json: 식별자, 이름, 단계, 파일 경로, 진행 링 사양

모든 개별 SVG는 투명 배경, viewBox="0 0 120 120". 루트 그룹 이름은 badge_{종류}_{단계}. 하위 frame / symbol 그룹을 분리했습니다. 그라데이션·필터·외부 이미지·폰트 없이 단색 면과 선만 사용합니다. 미리보기 시트의 글자는 개별 배지에 포함되지 않습니다.

## 시각 체계
1단계: 샌드 원형 메달과 얇은 하이라이트.
2단계: 액티브 블루, 16개 구슬 외곽과 이중 링.
3단계: 골드, 왕관·방사형 외곽·날개·하단 리본.
중앙 심볼의 경로·좌표·색은 받음 단계 전반에 걸쳐 고정됩니다. 첫 시동은 1단계 틀의 단일 배지입니다.

|---|---|---|---|

## 진행 중 링
잠김 도형 위에 원형 트랙과 진행 호를 별도 합성합니다. 중심 (60,60), 반지름 56, 선 두께 3, 시작 -90°, 시계 방향. 단계별 색은 #E4DCD3 / #00AAD2 / #FFC56B. SVG 기준 circumference=351.858377, dashoffset=circumference*(1-progress). 0%는 호를 숨기고, 100%는 닫힌 원으로 그립니다. 3단계 장식 주변에서 링이 가까워질 수 있으므로 앱에서는 배지 바깥 8px 여백에 별도 링을 그리는 방식을 권장합니다. 잠김 상태에는 링을 숨깁니다.

## 업그레이드 연출
총 1.5초, 소리 없음. 프레임 SVG를 순서대로 사용하거나 Compose에서 동일한 타이밍으로 재구현할 수 있습니다. Lottie JSON은 포함하지 않았습니다.
- 0~300ms: 이전 메달 외곽이 최대 1.07배 확대
- 300~900ms: 다음 외곽이 0.78→1배로 펼쳐지고 블루→골드 교차 전환
- 900~1230ms: 리본이 위에서 내려오며 나타남
- 1230~1500ms: 작은 반짝임이 나타났다 사라지고 최종 메달 유지
- 중앙 심볼은 연출 중에도 고정
- 모션 감소 설정에서는 마지막 프레임으로 즉시 전환

표준 SVG 애니메이션(SMIL)은 브라우저 미리보기용이며 Android SVG 로더의 지원을 가정하지 않습니다. Android에서는 프레임 시퀀스 또는 Compose 재구현을 사용하세요.
