# 카카오 QR 로그인 만들기

차 화면에 QR을 띄우고 휴대폰에서 카카오 로그인을 하면 차가 로그인되는 구조입니다.
카카오는 TV·차량용 "기기 로그인"을 따로 제공하지 않아서, 이 폴더의 작은 서버(`server.js`)가 휴대폰과 차 사이를 이어 줍니다.

키와 서버가 없으면 앱은 **시연용 로그인**으로 동작합니다. QR은 뜨지만 아무 데도 연결되지 않고, 화면에서 이름·번호를 넣어 로그인한 것처럼 처리합니다.

## 1. 카카오 개발자 앱 만들기

카카오 개발자 콘솔의 메뉴 이름은 바뀔 수 있습니다. 아래는 2026년 11월 기준 흐름입니다.

1. https://developers.kakao.com 에 카카오 계정으로 로그인합니다.
2. **내 애플리케이션 → 애플리케이션 추가하기**에서 앱 이름(예: 카로그)과 회사명을 넣습니다.
3. **앱 키**에서 **REST API 키**를 복사해 둡니다. (서버의 `KAKAO_REST_API_KEY`)
4. **카카오 로그인**을 **활성화(ON)** 합니다.
5. **Redirect URI**에 `https://내서버주소/oauth/kakao`를 등록합니다. 서버의 `PUBLIC_URL`과 정확히 같아야 합니다.
6. **동의항목**에서 닉네임을 켭니다.
   - **이름·전화번호**는 **비즈 앱 전환(사업자 정보 등록)과 동의항목 검수**를 마쳐야 받을 수 있습니다.
   - 검수 전에는 닉네임만 오고 번호는 비어 있습니다. 앱은 그래도 동작하며, 기록에 번호가 빈칸으로 남습니다.
7. (선택) **보안 → Client Secret**을 켰다면 그 값을 `KAKAO_CLIENT_SECRET`으로 넣습니다.

## 2. 서버 실행

Node.js 18 이상이 필요합니다. 추가 패키지는 없습니다.

```bash
cd server/kakao-qr
KAKAO_REST_API_KEY=복사한키 PUBLIC_URL=https://내서버주소 node server.js
```

- **휴대폰이 접속할 수 있는 주소**여야 합니다. 실제로는 클라우드 서버에 올리고 HTTPS 주소를 씁니다.
- 테스트할 때는 휴대폰과 맥이 같은 와이파이에 있으면 `PUBLIC_URL=http://맥IP:8787`로도 됩니다. 카카오 콘솔의 Redirect URI도 같은 주소로 맞춥니다.

## 3. 앱에 서버 주소 넣기

`HDapp/local.properties`에 한 줄 추가하고 다시 빌드합니다.

```
kakaoQrServer=https://내서버주소
```

- 에뮬레이터에서 맥에 띄운 서버로 붙을 때는 `kakaoQrServer=http://10.0.2.2:8787`처럼 씁니다. 다만 휴대폰이 열 QR 주소는 `PUBLIC_URL` 기준입니다.
- 이 값이 비어 있으면 시연용 로그인으로 돌아갑니다.
